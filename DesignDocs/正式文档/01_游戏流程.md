# 游戏流程

版本：v1.0

---

## 术语定义

| 术语 | 含义 |
|------|------|
| **局** | 一次完整的新游戏，从开局到通关或失败 |
| **层** | 局内的一个阶段，包含准备阶段和战斗阶段 |

---

## 一、游戏总览

一局游戏由 **初始选择** + **20 层** 组成。

```
初始选择
  │
  ▼
第1层
  ├── 准备阶段（摇人/撸铁/命运/抉择/猫市）
  └── 战斗阶段
        │
        ▼
第2层
  ├── 准备阶段
  └── 战斗阶段
        │
        ▼
      ...
        │
        ▼
第20层
  ├── 准备阶段
  └── 战斗阶段
        │
        ▼
  游戏结束（胜利/失败）
```

---

## 二、准备阶段玩法

准备阶段包含以下玩法，具体哪些层触发由配置决定：

| 玩法 | 包装名 | 强制性 | 说明 |
|------|--------|--------|------|
| 获得新兵种 | **摇人（新兵种）** | 强制 | 从未在摇人中出现过的兵种中选择一个加入 |
| 已有兵种增加数量 | **摇人（加数量）** | 强制 | 为已有兵种增加数量 |
| 获得兵种词缀 | **撸铁** | 强制 | 词缀选择的包装 |
| 商店交易 | **猫市** | 非强制 | 自由买卖 |
| 祈愿/祝福 | **命运** | 强制 | 选择兵种 + 效果 + 消耗档位 |
| 随机事件 | **抉择** | 强制 | 二选一，低风险/高风险 |

---

## 三、摇人的两种类型与触发时机

### 摇人（新兵种）

获得一个全新的兵种，按数量 A 配置获得。

| 时机 | 触发条件 | 玩家操作 |
|------|----------|----------|
| **开局** | 新游戏开始 | 两次 3 选 1，每次选 1 个兵种，共获得 2 个兵种 |
| **中途加入** | 可配置（如第10层） | 3 选 1，选 1 个兵种，获得第 3 个兵种 |

### 摇人（加数量）

为已有的兵种增加数量，按数量 B 配置获得。

| 时机 | 触发条件 | 玩家操作 |
|------|----------|----------|
| **扩容** | 可配置（如奇数层） | 从已有兵种中选择一个，为其增加数量 |

> 数量 A = 新兵种时的数量；数量 B = 加数量时的数量。不同兵种可分开配置。

---

## 四、弹出优先级

当同一层有多个玩法同时触发时，按以下顺序依次弹出：

```
摇人（新兵种·开局） > 摇人（新兵种·中途） > 撸铁 > 摇人（加数量） > 命运 > 抉择
```

所有强制玩法结束后，若有猫市，玩家可自行选择是否参与。

---

## 五、撸铁特殊规则

- 正常层：撸铁出现 1 次（3 选 1）
- 当玩家上一层选择了"极难"难度并通关：下一层准备阶段撸铁出现 **2 次**（2 次独立选择）

## 六、层结构

### 6.1 层类型分布

| 层 | 类型 | 难度 | 说明 |
|------|------|------|------|
| 1 | 普通 | ★ | 教学关 |
| 2 | 普通 | ★ | |
| 3 | 精英 | ★★ | 首个精英关 |
| 4 | 普通 | ★ | |
| 5 | **Boss** | ★★★ | 第一个 Boss |
| 6 | 普通 | ★★ | 中期开始 |
| 7 | 普通 | ★★ | |
| 8 | 精英 | ★★★ | |
| 9 | 普通 | ★★ | |
| 10 | **Boss** | ★★★★ | + 可选第 3 个兵种 |
| 11 | 普通 | ★★★ | 后期开始 |
| 12 | 精英 | ★★★★ | |
| 13 | 普通 | ★★★ | |
| 14 | 普通 | ★★★ | |
| 15 | **Boss** | ★★★★ | |

**统计：** 普通 12 层 / 精英 5 层 / Boss 3 层

### 6.2 敌人属性计算

```
敌人最终属性 = 怪物基础数值 × 当前层系数 × 该层独立调整参数
```

### 6.3 战斗产出

| 产出类型 | 来源 | 说明 |
|----------|------|------|
| 猫粮 | 战斗胜利 | 数量与选择的难度选项绑定 |
| 饰品 | 概率掉落 | 每层独立判定，优先掉落未拥有的 |
| 一次性道具 | 概率掉落 | 每层独立判定 |

## 七、状态转移条件

### 7.1 正常流转

```
初始选择 ──→ 第 1 层准备阶段
第 N 层战斗结束 ──→ 第 N+1 层准备阶段（N < 20）
第 20 层战斗结束 ──→ 游戏胜利（击败 Boss）/ 游戏失败（未击败）
```

### 7.2 失败条件

```
战斗中所有出战兵种全部阵亡 → 战斗失败
  │
  ├─→ 随机损失 1 个出战兵种（全部阵亡）
  └─→ 仅剩 1 个兵种时再失败 → 游戏结束
```

### 7.3 阵亡恢复

```
兵种阵亡 → 下层立即恢复（满血复活）
```
