# 游戏流程

版本：v3.0

---

## 术语定义

| 术语 | 含义 |
|------|------|
| **局** | 一次完整的新游戏，从开局到通关或失败 |
| **关** | 局内的一个战斗节点，包含准备阶段和战斗阶段 |
| **地区** | 一组关卡的集合，含独立的敌人种类、可招募物种和背景美术 |
| **据点** | 战场上可摆放单位的光圈位置 |
| **看板** | 战场后方的大型单位，拥有极高血量和可观攻击力 |
| **人口** | 上阵单位的容量限制，由主角"领导力"属性决定 |
| **连携技** | 特定标签组合的单位同时在场时自动触发的特殊效果 |
| **后勤** | 不参与战斗、在基地持续产出资源的单位定位 |
| **上阵** | 编入战斗队伍、可在关卡中使用的单位定位 |
| **木天蓼叶** | 通用货币，用于商店购买、招募提升等 |

---

## 一、游戏总览

一局游戏由 **初始选择** + **50 关** 组成，分布在 **3 个地区**中。包含 **3 次 Boss 关**（第 15 关、第 30 关、第 50 关附近）。

```
初始选择（选择初始单位）
  │
  ▼
═══ 地区 1 ═══
第 1 关 ──→ 地图选择 ──→ 准备阶段 ──→ 战斗阶段
第 2 关 ──→ 地图选择 ──→ 准备阶段 ──→ 战斗阶段
  ...
第 15 关（Boss）──→ 战斗阶段 ──→ 地区切换
  │
  ▼
═══ 地区 2 ═══
第 16 关 ──→ 地图选择 ──→ 准备阶段 ──→ 战斗阶段
  ...
第 30 关（Boss）──→ 战斗阶段 ──→ 地区切换
  │
  ▼
═══ 地区 3 ═══
第 31 关 ──→ 地图选择 ──→ 准备阶段 ──→ 战斗阶段
  ...
第 50 关（最终 Boss）──→ 战斗阶段
  │
  ▼
游戏结束（胜利 / 失败）
```

## 二、关卡系统

### 2.1 关卡结构

| 项目 | 数值 |
|------|------|
| 总关数 | 50 关 |
| Boss 关 | 3 次（第 15、30、50 关附近，具体待调） |
| 地区数 | 3 个 |
| 普通关 | 47 关 |

### 2.2 地区切换

- 每次 Boss 关后切换至下一地区
- 地区切换意味着：
  - 新的敌人种类
  - 新的可招募物种
  - 新的背景美术

### 2.3 关卡选择

每关结束后，玩家从**地图 UI** 中选择下一关。

地图上显示多个可选节点，节点上显示情报（取决于主角"街头情报"等级）：

| 街头情报等级 | 显示内容 |
|-------------|----------|
| Lv.0 | 不显示敌方信息 |
| Lv.1 | 模糊描述（"少量"/"大量"） |
| Lv.2 | 大致范围（"10-20只"） |
| Lv.3 | 精确数字 + 敌方首领头像 |

### 2.4 关卡类型

| 类型 | 说明 |
|------|------|
| **普通战斗** | 标准环形战场战斗 |
| **商店** | 消耗木天蓼叶购买单位、道具、增益 |
| **随机事件** | 触发特殊剧情或选择，可能获得单位、资源、增益或减益 |

### 2.5 Boss 关

**触发条件**：累计关卡数达到预设节点（15 / 30 / 50）

**Boss 关特殊规则**：
- 全员强制上阵：当前拥有的所有单位（含后勤）全部参战
- 人口限制在 Boss 关暂时解除
- 所有单位出现在布阵界面，可自由摆放
- 后勤单位在 Boss 关的战斗属性与普通单位相同

**Boss 关结算**：
- 胜利后，所有单位（含在战斗中阵亡的）全部复活
- 给予 Boss 关专属奖励（解锁新物种 / 看板能力提升 / 稀有道具）
- 切换至下一地区

**失败处理**：
- Boss 关失败 → 本局结束，进入结算界面

## 三、准备阶段玩法

准备阶段包含以下玩法系统：

| 系统 | 包装名 | 强制性 | 说明 |
|------|--------|--------|------|
| 祈愿/祝福 | **命运** | 强制 | 选择档次 + 祝福 + 消耗猫粮 |
| 随机事件 | **抉择** | 强制 | 二选一，低风险/高风险 |
| 商店交易 | **猫市** | 非强制 | 自由买卖 |

### 弹出优先级

同一关有多个准备事件时，按优先级从高到低依次弹出：

```
命运 20 > 抉择 10 > 猫市 0
```

所有强制事件结束后，若有猫市，玩家可自行选择是否参与。

## 四、战斗系统

### 4.1 环形战场

**战场结构**：
- 战场为一个环形擂台，分为三个区域层级：

| 区域 | 允许进入的单位 | 据点大小 |
|------|---------------|----------|
| 内圈 | 轻量级 | 小圈 |
| 中圈 | 轻量级 + 中量级 | 中圈 |
| 外圈 | 重量级 | 大圈 |

- 每个区域内分布若干可摆放单位的"据点"（光圈）

**看板位置**：
- 我方看板固定在外圈之外的"后方区"
- 敌方看板固定在对面外圈之外的"后方区"
- 看板不占据据点，有独立的位置槽位

### 4.2 布阵规则

**敌方布阵**：
- 敌人阵型为预设数据，由关卡配置决定
- 玩家进入布阵界面时，敌方单位已全部摆放完毕
- 玩家可查看敌方所有单位的位置、类型

**我方布阵**：
- 玩家将自己拥有的单位拖拽至任意空据点
- 无"己方半场"限制，环形战场可任意落位
- 单位必须放入符合其重量级要求的据点（轻量级单位不可放入重量级据点）
- 布阵有时间限制或无限时，取决于关卡设定

**人口限制**：

| 单位重量级 | 人口消耗 |
|-----------|----------|
| 轻量级 | 1 |
| 中量级 | 2 |
| 重量级 | 3 |
| 特殊单位 | 0（不占人口） |

- 当前人口上限由主角"领导力"属性决定

### 4.3 战斗流程

**战斗开始**：
- 布阵确认后进入战斗，所有单位按物理规则自动战斗
- 战斗为实时物理乱斗，非回合制
- 单位自动寻找最近敌人攻击

**看板规则**：

| 阶段 | 我方看板状态 | 敌方看板状态 |
|------|-------------|-------------|
| 我方小兵存活中 | 休眠（不攻击、不可被攻击、无敌） | 休眠 |
| 我方小兵全灭 | 激活：开始攻击，可被敌方攻击 | 休眠 |
| 敌方小兵全灭 | 激活 | 激活：可被我方攻击，被攻击时掉落货币 |

**看板属性**：
- 看板拥有极高血量
- 看板拥有可观攻击力（前期可有效清理残血敌人，但无法独挡大军）
- 看板攻击为远程自动攻击，优先攻击最近的敌方单位

### 4.4 战斗结算

**胜利条件**：敌方小兵全灭 + 敌方看板被摧毁

**失败条件**：我方小兵全灭 + 我方看板被摧毁

**物理说服触发**：
- 敌方首领单位在战斗中被击败时，标记为"被说服"
- 战斗胜利后，被标记的首领及其所属小兵全部加入我方
- 小兵单独被击败不会触发说服

**招募流程**：
- 战斗胜利后，显示"招募阶段"
- 被说服的首领头像亮起，显示加入概率
- 概率受主角属性、关卡设定影响
- 玩家确认招募后，该单位及其随从加入我方
- 未被说服的敌方小兵自动消失

**资源获取**：
- 攻击敌方看板期间，看板持续掉落货币（木天蓼叶）
- 摧毁看板时，爆发大量货币

## 五、单位系统

### 5.1 单位属性

| 属性 | 说明 |
|------|------|
| 名称 | 单位显示名 |
| 物种 | 猫/犬/鸟/其他 |
| 重量级 | 轻量/中量/重量 |
| 人口消耗 | 1/2/3/0 |
| 生命值 | 生命上限 |
| 攻击力 | 每次攻击伤害 |
| 攻击速度 | 攻击频率 |
| 移动速度 | 移动快慢 |

### 5.2 被动技能

- 每个单位拥有一个被动技能
- 被动技能在战斗中持续生效
- 部分被动技能标记为"不分敌我"，对全场所有单位生效
- 被动技能在单位死亡后失效

### 5.3 标签系统

- 每个单位携带若干标签（如：猫科、飞行、近战、远程）
- 标签用于连携技触发判定

### 5.4 连携技

**触发条件**：
- 特定标签组合的单位同时在场时，自动触发连携效果
- 例：场上同时存在"飞行"标签单位和"犬科"标签单位时，触发"天降正义"效果

**效果类型**：
- 属性增益（全员攻击力提升）
- 特殊攻击（对敌方全体造成一次伤害）
- 控制效果（敌方全体减速）
- 召唤效果（召唤临时单位）

**连携技在战斗开始前预览**：
- 布阵界面显示当前阵容可触发的连携技列表
- 帮助玩家决策阵容搭配

### 5.5 单位获取

| 获取方式 | 说明 |
|----------|------|
| 战斗招募 | 击败敌方首领后概率获得（物理说服） |
| 事件获取 | 关卡间随机事件可能触发单位加入 |
| 初始单位 | 每局开始，玩家拥有固定初始单位 |

## 六、主角系统

### 6.1 主角定位

- 主角不上场战斗
- 主角在场边作为"总大将"存在
- 主角属性影响全局战斗和运营

### 6.2 主角属性

| 属性 | 说明 |
|------|------|
| 等级 | 通过战斗经验提升 |
| 领导力 | 决定人口上限（初始 3，每级 +1，上限待定） |
| 街头情报 | 决定战前情报精度（Lv.0~3） |
| 咪格魅力 | 提升首领招募概率 |

### 6.3 主角技能树

- 每次升级获得 1 技能点
- 技能树包含三条分支：

| 分支 | 效果方向 |
|------|----------|
| 武斗派 | 提升开场全体攻击力/攻速 |
| 防御派 | 提升看板血量/开场护盾 |
| 仁义派 | 降低招募难度/提升后勤产出 |

- 玩家可自由分配技能点

---

## 七、后勤系统

### 7.1 二分法机制

- 每个招募到的单位，玩家选择其定位：

| 定位 | 说明 |
|------|------|
| **上阵** | 编入战斗队伍，可在后续关卡中使用 |
| **后勤** | 编入基地，不再参与战斗（除 Boss 关），但持续产出资源 |

- 定位一旦选择，在当前地区内不可更改
- Boss 关结束后，可重新分配所有单位的定位

### 7.2 后勤产出

**产出规则**：
- 每通过一关（无论关卡类型），后勤单位自动产出资源
- 产出类型和数量取决于单位的物种和稀有度

**产出类型示例**：

| 物种 | 产出 |
|------|------|
| 柴犬 | 木天蓼叶（通用货币） |
| 乌鸦 | 情报点（揭露隐藏信息） |
| 狸猫 | 随机道具 |
| 老猫 | 经验值（加速主角升级） |

**产出可视化**：
- 在基地界面，后勤单位有独立的工作动画（如柴犬站店、乌鸦放哨）
- 过关后显示后勤产出汇总

### 7.3 基地

- 基地为一条可滚动的街道"不夜猫町"
- 战斗单位在街上游荡、训练
- 后勤单位在各自岗位（店铺、哨点）工作
- 基地仅作为视觉呈现，不涉及建造操作

## 八、道具与经济

### 8.1 货币

**木天蓼叶**：通用货币
- 获取途径：战斗胜利、攻击敌方看板、后勤产出、事件奖励
- 用途：商店购买、招募提升概率、特定事件消耗

### 8.2 道具

| 类型 | 说明 |
|------|------|
| 消耗品 | 一次性战斗增益（攻击药、护盾药等） |
| 装备品 | 装备给特定单位，持续生效（项圈、羽织等） |
| 特殊品 | 改变规则的道具（如"下一场战斗人口限制解除"） |

### 8.3 商店

- 商店为可选关卡类型
- 提供单位购买、道具购买、增益购买
- 商品随机刷新

---

## 九、局外成长

### 9.1 声望系统

- 每局结束后，根据成绩获得"声望"
- 声望用于解锁：

| 解锁内容 | 说明 |
|----------|------|
| 新的初始单位选择 | 开局可选不同的初始单位 |
| 新的可招募物种 | 更多物种加入招募池 |
| 新的被动技能池 | 更多被动技能可用 |
| 外观/皮肤 | 装饰性内容 |

### 9.2 存档

- 战斗中不可存档
- 每关选择完成后自动存档
- 一局未完成可暂停，下次继续
- 放弃当前局返回主菜单时，当前局进度作废

## 十、状态转移条件

### 10.1 正常流转

```
初始选择 ──→ 第 1 关（地图选择 → 准备阶段 → 战斗阶段）
第 N 关战斗结束 ──→ 第 N+1 关地图选择（N < 50）
第 50 关战斗结束 ──→ 游戏胜利
```

### 10.2 Boss 关流转

```
第 15/30 关战斗胜利 ──→ 地区切换 → 下一关地图选择
第 50 关战斗胜利 ──→ 游戏胜利
Boss 关战斗失败 ──→ 游戏结束
```

### 10.3 失败条件

```
我方小兵全灭 + 我方看板被摧毁 → 战斗失败
  │
  ├─→ Boss 关：本局结束
  └─→ 普通关：损失本次战斗单位（待定）
```

### 10.4 阵亡恢复

```
普通关战斗结束 → 参战单位恢复（满血复活）
Boss 关战斗结束 → 所有单位恢复（含阵亡的）
```

## 十一、关卡配置数据结构

```
LevelConfig {
    levelId:        关卡编号（1~50）
    regionId:       所属地区（1~3）
    isBoss:         是否 Boss 关
    difficulty:     难度系数
    enemyFormation: 敌方阵型配置
    levelType:      关卡类型（Battle / Shop / Event）
}
```

---

## 十二、单位数据结构

```
UnitConfig {
    unitId:         单位唯一 ID
    name:           显示名
    species:        物种（Cat / Dog / Bird / Other）
    weightClass:    重量级（Light / Medium / Heavy）
    populationCost: 人口消耗（0/1/2/3）
    maxHp:          生命值
    attack:         攻击力
    attackSpeed:    攻击速度
    moveSpeed:      移动速度
    passiveSkillId: 被动技能 ID
    tags:           标签列表（如 ["cat", "melee", "flying"]）
    avatarId:       外观 ID
}
```

---

## 十三、布阵数据结构

```
FormationConfig {
    slots:          据点列表
        [
            {
                position:   世界坐标
                weightClass: 允许的重量级（Light / Medium / Heavy / Any）
            }
        ]
    billboardPos:   看板位置
    deployTimeLimit: 布阵时间限制（秒，0=无限）
}
```
