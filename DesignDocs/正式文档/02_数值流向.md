# 数值流向

版本：v1.0

---

## 一、数值分层

游戏中的数值分为四层：

| 层级 | 名称 | 生命周期 | 说明 |
|------|------|----------|------|
| **局外层** | 跨局成长 | 多局游戏 | 暂无内容，预留 |
| **永久层** | 局内成长 | 整局游戏（20 层） | 词缀效果、装备加成、属性提升 |
| **层内效果** | 层内效果 | 单层 | 限时 buff、命运效果 |
| **战斗层** | 战斗内成长 | 单场战斗 | 毒层、饱食层数、充能、击杀累积 |

## 二、各来源的数值归属

| 来源 | 获得的数值类型 | 归属层级 | 说明 |
|------|--------------|----------|------|
| **摇人（新兵种）** | 新兵种 + 数量 | 永久层 | 兵种永久加入 |
| **摇人（加数量）** | 增加数量 | 永久层 | 永久加入 |
| **撸铁** | 词缀效果 | 永久层 | 本局永久生效 |
| **命运** | 兵种属性提升（绝对值/百分比） | 永久层 | 本局永久生效 |
| **命运** | 兵种品质提升 | 永久层 | 品质永久变化 |
| **命运** | 饰品 | 永久层 | 装备效果持续生效 |
| **命运** | 猫粮 | 货币 | 即时持有 |
| **抉择** | 各类奖励（道具/猫粮/属性） | 按选项不同 | 永久或限时 |
| **猫市** | 奇物（装备） | 永久层 | 装备效果持续生效 |
| **猫市** | 兵种 | 永久层 | 兵种永久加入 |
| **猫市** | 一次性道具 | 层内效果 | 使用后消失 |
| **战斗胜利** | 猫粮 | 货币 | 即时获得 |
| **战斗胜利** | 饰品/道具（概率） | 永久层/层内效果 | 按类型判定 |
| **战斗内** | 毒/饱食/充能等层数 | 战斗层 | 战斗结束清零 |
| **战斗内** | 击杀累积的攻击力 | 战斗层 | 战斗结束清零 |

## 四、关键数值流向规则

### 4.1 兵种属性流向

```
兵种基础属性（配置初始值）
  │
  ├─→ 命运提升（+绝对值或×百分比）──→ 永久生效
  ├─→ 词缀加成（+绝对值或×百分比）──→ 永久生效
  ├─→ 装备/奇物加成 ──→ 永久生效
  │
  └─→ 战斗前最终计算 ──→ 战斗内使用
                          │
                          ├─→ 地形/天气修正 ──→ 仅本场战斗
                          └─→ 战斗内 buff ──→ 仅本场战斗
```

### 4.2 战斗内层数流向

```
战斗开始 → 层数从 0 开始
  │
  ├─→ 击杀/施法/攻击命中 → 层数增长
  │     （毒层、饱食、充能、猎手专注等）
  │
  └─→ 战斗结束 → 所有层数清零
                  │
                  └─→ 下一场战斗重新从 0 开始
```

## 五、货币流向

### 5.1 猫粮流向

```
猫粮来源：
  ├─ 初始猫粮（可配置）
  ├─ 战斗胜利奖励
  ├─ 命运奖励
  ├─ 猫市卖出道具
  ├─ 抉择奖励
  └─ 战利品掉落

猫粮消耗：
  ├─ 命运消耗（可配置多档位）
  ├─ 猫市购买（奇物/道具/兵种）
  ├─ 猫市刷新（递增消耗）
  └─ 出战消耗（选择出战兵种时，可配置）
```

### 5.2 猫粮存量影响

- 猫粮是唯一货币，贯穿全局
- 命运消耗影响产出品质（低档蓝紫 / 中档紫金 / 高档金橙）
- 猫市刷新消耗递增，鼓励理性消费
- 战斗产出与难度选项绑定，高风险高回报
