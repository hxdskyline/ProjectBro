# 战前准备

版本：v2.0

---

## 一、系统概述

战前准备是每一关战斗前的阶段。玩家从地图中选择下一关后，系统按优先级依次弹出该关配置的玩法事件（命运、抉择），玩家依次完成所有强制事件后，可自由逛猫市、查看阵容，最终进入布阵界面调整站位，点击"开始战斗"进入战斗。

**关键变更（相对 v1.0）**：
- 移除摇人（招募）系统
- 移除撸铁（附魔/Buff）系统
- 移除难度选择机制
- 新增地图选择环节（替代旧版层选择）
- 战斗准备阶段改为布阵操作（非难度选择）

---

## 二、整体流程

```
关卡开始
  │
  ├─ 地图选择
  │    └─ 玩家从地图 UI 选择下一关节点
  │
  ├─ 弹窗事件队列（按优先级依次弹出）
  │    ├─ 命运（祈愿/祝福）  优先级 20
  │    ├─ 抉择（随机事件）    优先级 10
  │    └─ 猫市（商店交易）    优先级 0（不强制弹出）
  │
  ├─ 自由阶段
  │    ├─ 查看阵容
  │    ├─ 进入猫市（可选）
  │    └─ 点击"开始战斗"
  │
  └─ 战斗准备（布阵）
       ├─ 查看敌方布阵
       ├─ 我方布阵（拖拽单位至据点）
       ├─ 确认人口限制
       └─ 进入战斗
```

## 三、地图选择

每关结束后，玩家从**地图 UI** 中选择下一关。

### 3.1 节点类型

地图上显示若干可选节点，节点类型包括：

| 类型 | 说明 |
|------|------|
| **普通战斗** | 标准环形战场战斗，推进关卡进度 |
| **商店（猫市）** | 消耗木天蓼叶购买单位、道具、增益 |
| **随机事件** | 触发特殊剧情或选择，可能获得单位、资源、增益或减益 |
| **Boss 关** | 强制全员上阵的首领战（仅出现在第 15、30、50 关附近） |

### 3.2 情报显示

节点上显示的情报内容取决于主角"街头情报"属性等级：

| 街头情报等级 | 显示内容 |
|-------------|----------|
| Lv.0 | 不显示任何敌方信息 |
| Lv.1 | 模糊描述（"少量敌人"、"大量敌人"） |
| Lv.2 | 大致范围（"敌人约 10-20 只"） |
| Lv.3 | 精确数字 + 敌方首领头像 |

### 3.3 Boss 关特殊规则

- Boss 关出现在第 15、30、50 关附近（具体关号待调）
- Boss 关前地图节点会标注为 Boss 图标
- Boss 关详情参见 `01_基础_游戏流程.md` 第 2.5 节

## 四、弹窗事件队列

### 4.1 事件来源

每关有哪些事件由关卡配置决定。系统读取当前关的配置，将存在的事件加入队列。

### 4.2 优先级排序

队列中的事件按优先级从高到低排序，严格串行弹出：

| 优先级 | 事件 | 说明 |
|--------|------|------|
| 20 | 命运（祈愿/祝福） | 最先弹出，强制完成 |
| 10 | 抉择（随机事件） | 其次弹出，强制完成 |
| 0 | 猫市（商店交易） | 最后，不强制弹出 |

### 4.3 串行执行

- 同一时刻最多显示一个弹窗
- 玩家完成当前事件后，自动弹出下一个事件
- 所有强制事件（命运、抉择）完成后，若有猫市，弹出猫市入口提示（可选择不进入）
- 所有事件处理完毕后，进入自由阶段

### 4.4 完成状态追踪

- 每种事件在每关最多执行一次
- 即使中途退出重新进入，已完成的事件会被跳过

## 五、命运

命运是祈愿/祝福系统的包装名称。玩家选择档次 + 祝福效果，消耗木天蓼叶获取随机单位或增益。

- **强制事件**：每关有命运事件时必须完成
- **详细规则**参见 `105_系统_命运.md`

---

## 六、抉择

抉择是随机事件系统的包装名称。玩家面对两个选项：低风险/高风险，不同选择带来不同结果（资源、单位、增益或减益）。

- **强制事件**：每关有抉择事件时必须完成
- **详细规则**参见 `106_系统_抉择.md`

---

## 七、猫市

猫市是商店交易系统的包装名称。玩家可自由买卖单位、道具和增益，使用木天蓼叶作为货币。

- **非强制事件**：玩家可选择不进入
- **详细规则**参见 `104_系统_猫市.md`

---

## 八、战斗准备

所有事件处理完毕后，玩家点击"开始战斗"进入布阵界面。

### 8.1 查看敌方布阵

- 进入布阵界面时，敌方单位已全部摆放完毕
- 玩家可查看敌方所有单位的位置、类型、数量

### 8.2 我方布阵

玩家将自己拥有的单位拖拽至战场据点：

- **拖拽操作**：从单位列表拖拽至空据点
- **重量级限制**：单位必须放入符合其重量级要求的据点
  - 轻量级单位 → 内圈据点
  - 轻量级 + 中量级单位 → 中圈据点
  - 重量级单位 → 外圈据点
- **无半场限制**：环形战场可任意落位，不限制己方区域

### 8.3 人口限制

| 单位重量级 | 人口消耗 |
|-----------|----------|
| 轻量级 | 1 |
| 中量级 | 2 |
| 重量级 | 3 |
| 特殊单位 | 0（不占人口） |

- 当前人口上限由主角"领导力"属性决定
- **Boss 关解除人口限制**：所有单位（含后勤）全部上阵，无人口上限

### 8.4 开始战斗

确认布阵后点击"开始战斗"，进入战斗阶段。

---

## 九、战斗结束后

### 9.1 普通关

- 参战单位恢复（满血复活）
- 处理限时 buff 衰减
- 后勤单位自动产出资源
- 推进关卡进度
- 保存存档
- 进入下一关的地图选择

### 9.2 Boss 关

- **所有单位恢复**（含在战斗中阵亡的，全部满血复活）
- 给予 Boss 关专属奖励（解锁新物种 / 看板能力提升 / 稀有道具）
- **切换至下一地区**（新敌人种类、新背景美术）
- **可重新分配所有单位定位**：玩家可将后勤单位调为上阵，或将上阵单位调为后勤
- 保存存档
- 进入下一关的地图选择
