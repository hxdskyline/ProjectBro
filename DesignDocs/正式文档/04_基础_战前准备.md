# 战前准备

版本：v1.0

---

## 一、系统概述

战前准备是每层战斗前的阶段。系统按优先级依次弹出该层配置的玩法事件，玩家依次完成所有强制事件后，进入自由阶段，可查看阵容、使用道具、逛猫市，最终点击"开始战斗"进入战斗。

---

## 二、整体流程

```
层开始
  │
  ├─ 弹窗事件队列（按优先级依次弹出）
  │    ├─ 摇人（新兵种）  优先级 40
  │    ├─ 撸铁            优先级 30
  │    ├─ 命运            优先级 20
  │    ├─ 抉择            优先级 10
  │    └─ 猫市            优先级 0（仅提示，不强制弹出）
  │
  ├─ 自由阶段
  │    ├─ 查看阵容
  │    ├─ 使用道具
  │    ├─ 进入猫市（可选）
  │    └─ 点击"开始战斗"
  │
  └─ 战斗准备
       ├─ 选择出战兵种
       ├─ 选择难度选项
       └─ 进入战斗
```

---

## 三、弹窗事件队列

### 3.1 事件来源

每层有哪些事件由配置文件决定。系统读取当前层的配置，将存在的事件加入队列。

### 3.2 优先级排序

队列中的事件按优先级从高到低排序，严格串行弹出：

| 优先级 | 事件 | 说明 |
|--------|------|------|
| 40 | 摇人（新兵种） | 最先弹出 |
| 30 | 撸铁 | 其次 |
| 20 | 命运 | 再次 |
| 10 | 抉择 | 最后弹出的强制事件 |
| 0 | 猫市 | 不强制弹出，仅提示 |

### 3.3 串行执行

- 同一时刻最多显示一个弹窗
- 玩家完成当前事件后，自动弹出下一个事件
- 所有强制事件完成后，进入自由阶段

### 3.4 完成状态追踪

- 每种事件在每层最多执行一次
- 即使中途退出重新进入，已完成的事件会被跳过

---

## 四、自由阶段

所有强制事件完成后，玩家可自由操作：

- **查看阵容**：查看当前拥有的兵种、属性、buff 等信息
- **使用道具**：使用已购买的一次性消耗品
- **逛猫市**：自由进出猫市进行买卖（非强制）
- **开始战斗**：点击按钮进入战斗准备

---

## 五、战斗准备

点击"开始战斗"后进入战斗准备界面：

### 5.1 选择出战兵种

- 玩家从已拥有的兵种中选择出战单位
- 至少选择 1 个兵种

### 5.2 选择难度选项

根据关卡类型生成不同的难度选项：

| 关卡类型 | 难度选项 |
|----------|----------|
| **普通关** | 2 个普通难度选项 |
| **精英关** | 2 个普通选项 + 1 个极难选项 |
| **Boss 关** | 1 个"血战"难度选项 |

难度选项关联不同的地形、天气和奖励。

### 5.3 进入战斗

确认选择后加载战斗场景，开始战斗。

---

## 六、战斗结束后

战斗结束后自动推进到下一层：
1. 处理限时 buff 衰减
2. 推进层数
3. 保存存档
4. 进入下一层的战前准备阶段
