《猫猫部落》战斗系统说明
========================================

【战斗参与者】

每场战斗中参与者：
- 族长（Leader）：每个族群必须有一个族长
- 小猫（Cats）：族长带领的士兵

【属性来源】

族长属性：
├─ 来自: tribe_config.json > leaderBaseStats
├─ 品质: 仅族长有品质（初始为白色）
└─ 计算: LeaderBaseStats + 加成(永久/临时)

小猫属性：
├─ 来自: tribe_config.json > catBaseStats（现在有独立配置）
├─ 品质: 小猫有品质（白/蓝/紫/金）
├─ 属性乘数: 根据品质产生10-50%的属性倍数
└─ 计算: catBaseStats * 品质乘数

【配置示例】

```json
{
  "tribeType": 0,
  "tribeName": "缅因猫族",
  "initialCatCount": 3,
  "leaderBaseStats": {
    "attack": 100,      // 族长攻击
    "defense": 80,      // 族长防御
    "hp": 1000,         // 族长生命
    "speed": 1000,      // 族长速度
    "command": 10       // 族长统帅力（影响小猫速度惩罚）
  },
  "catBaseStats": {
    "attack": 70,       // 小猫基础攻击（无品质加成时）
    "defense": 55,      // 小猫基础防御
    "hp": 600,          // 小猫基础生命
    "speed": 700,       // 小猫基础速度
    "command": 0        // 小猫不使用统帅力
  }
}
```

【战斗流程】

1. 初始化战斗
   ├─ 加载族长属性: LeaderStats = 计算(leaderBaseStats + 加成)
   ├─ 加载小猫列表: 遍历tribe.cats
   └─ 计算小猫属性: CatStats = 计算(catBaseStats * 品质乘数)

2. 战斗进行
   ├─ 所有参与者(族长+小猫)参与战斗
   ├─ 使用相同的战斗逻辑和公式
   └─ 属性值不同(族长 > 小猫)

3. 战斗结束
   ├─ 统计伤害/死亡
   ├─ 小猫死亡: 下回合自动恢复（不需要休息）
   └─ 族长死亡: 需要休息指定回合后才能再次上阵

【属性计算算法】

小猫品质对属性的影响：
```
白色(White):   10-20% 加成
蓝色(Blue):    20-30% 加成
紫色(Purple):  30-40% 加成
金色(Gold):    40-50% 加成

实际属性 = catBaseStats × (1 + 品质乘数)
```

例如：缅因猫的小猫白色品质
```
基础: attack=70, defense=55, hp=600, speed=700
品质乘数: 10-20%（随机）
实际: attack=70×1.15=80.5≈81
      defense=55×1.15=63.25≈63
      hp=600×1.15=690
      speed=700×1.15=805
```

统帅惩罚：
```
当小猫数量 > 族长统帅力时，小猫速度下降：
下降幅度 = min((超出比例 × 10%), 50%)

例：族长统帅力=10，小猫15只
超出 = 5只
比例 = 5/10 = 50%
速度下降 = min(50% × 10%, 50%) = 10%
实际速度 = 基础速度 × (1 - 10%) = 基础速度 × 0.9
```

【战斗系统集成】

关键调用流程：
1. BattlePanel.StartBattle(deployedTribes)
2. 遍历小猫: TribeStatsCalculator.CalculateCatStats(cat, catBaseStats)
3. 传入战斗系统: BattleFlowController
4. 执行战斗: Unit combat with LeaderStats + CatStats

【开发检查清单】

实现战斗时需要确保：

□ 从tribe_config.json正确加载catBaseStats
□ 小猫属性计算使用catBaseStats而不是leaderStats
□ 品质乘数正确应用到小猫属性上
□ 统帅惩罚只影响小猫速度，不影响族长
□ 战斗系统支持多个小猫参与(列表遍历)
□ 战斗结束后正确处理小猫/族长的恢复逻辑
□ UI显示族长和小猫的不同属性

【数值平衡参考】

小猫属性 vs 族长属性 (建议比例)：
```
缅因猫:  小猫 70% (attack 70 vs 100)
狸花猫:  小猫 71% (attack 85 vs 120)
大橘猫:  小猫 71% (attack 78 vs 110)
奶牛猫:  小猫 71% (attack 60 vs 85)
暹罗猫:  小猫 71% (attack 92 vs 130)
布偶猫:  小猫 70% (attack 74 vs 105)

平均: 小猫约为族长的70%基础属性
```

这个比例保证了：
- 族长是小猫的强力版本
- 多个小猫可以弥补族长单体的不足
- 品质加成使小猫可以逐步变强
