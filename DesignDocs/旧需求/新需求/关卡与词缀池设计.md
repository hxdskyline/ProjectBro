## 一、核心机制概述

| 要素 | 说明 |
|------|------|
| 可选猫咪 | 8~10 种，初始选 2 种加入战斗小队 |
| 每种猫咪 | 1 个固有技能（初始自带）+ 20 个可选词缀 |
| 关卡总数 | 20 关，每关战斗结束后选 1 个词缀 |
| 中途加入 | 第 10 关前可选择第 3 个种族加入 |
| 词缀升级 | 低级词缀可被对应高级词缀覆盖；已选高级后不再出现同名低级/高级 |

## 三、词缀池机制

### 3.1 词缀分类

每种猫咪拥有 **20 个词缀**，分为三类：

| 类别 | 数量 | 规则 |
|------|------|------|
| **低级词缀** | 5 个 | 初始即可出现；被对应高级覆盖后不再出现 |
| **高级词缀** | 5 个 | 与低级一一对应；需先选过对应低级才出现；覆盖低级 |
| **固定词缀** | 10 个 | 完全独立，不与低级/高级关联；不会重复抽取 |

### 3.2 低级→高级对应关系

| 低级词缀 | 高级词缀 | 覆盖规则 |
|----------|----------|----------|
| 低级 A | 高级 A' | 选 A' 后，A 被移除，A 不再出现 |
| 低级 B | 高级 B' | 同上 |
| 低级 C | 高级 C' | 同上 |
| 低级 D | 高级 D' | 同上 |
| 低级 E | 高级 E' | 同上 |

- 已选高级后，该高级和对应的低级都从池中移除
- 未选低级时，高级也不会出现

### 3.3 词缀选择流程

```
战斗结束 → 根据当前关卡和难度从池中随机 N 个词缀 → 玩家选 1 个 → 应用到对应猫咪
```

- 每次展示 **3 个词缀**供选择（从加权池中抽取 3 个不重复的）
- 词缀作用于**选中的猫咪**（玩家在选择界面指定目标猫咪）
- 已拥有的词缀不会重复出现（固定词缀除外，固定词缀本身就不会重复）

## 四、抽取概率表

### 4.1 概率分布

根据关卡范围和关卡类型，三类词缀的出现概率不同：

| 关卡范围 | 关卡类型 | 低级 | 高级 | 固定 |
|----------|----------|------|------|------|
| 1~5 | 普通 | 80% | 0% | 20% |
| 1~5 | 精英/Boss | 50% | 0% | 50% |
| 6~10 | 普通 | 50% | 10% | 40% |
| 6~10 | 精英/Boss | 30% | 20% | 50% |
| 11~15 | 普通 | 20% | 30% | 50% |
| 11~15 | 精英/Boss | 0% | 50% | 50% |
| 16~20 | 普通 | 0% | 50% | 50% |
| 16~20 | 精英/Boss | 0% | 0% | 100% |

### 4.2 概率解读

- **前期（1~5）**：以低级词缀为主，帮助玩家快速搭建基础 build
- **中期（6~10）**：高级词缀开始出现，玩家开始升级核心词缀
- **后期（11~15）**：低级几乎消失，高级和固定各半
- **终局（16~20）**：普通关仍可选高级/固定；精英/Boss 关 100% 固定词缀（最强效果）

### 4.3 池子过滤规则

1. **已拥有的低级词缀**：如果对应高级已选，从池中移除
2. **已拥有的高级词缀**：从池中移除
3. **已拥有的固定词缀**：从池中移除（不重复抽取）
4. **未满足前置的高级词缀**：如果对应低级未选，从池中移除
5. **空池保护**：如果某类词缀全部被选完，剩余概率平分给其他类

### 8.1 词缀 → 现有系统映射

| 词缀类别 | 对应现有系统 | 说明 |
|----------|-------------|------|
| 低级词缀 | `TribeAuraOption`（T1 级） | 通过 `TribeAuraService` 加载，`BuffScopeFilter` 指定目标 |

### 8.2 抽取逻辑

```
AffixDrawService.Draw(level, difficulty, tribeType, ownedAffixes)

  ├── 从各池中过滤已拥有 / 不满足前置的词缀
  ├── 加权随机抽取 3 个不重复词缀
  └── 返回给 UI 展示
```

### 8.4 词缀数据结构（建议）

```csharp
[System.Serializable]
public class AffixData
{
    public string affixId;          // 唯一 ID，如 "COW_L1"
    public string displayName;      // 显示名，如 "淬毒之爪"
    public string description;      // 描述
    public int tribeType;           // 所属种族
    public AffixTier tier;          // Low / High / Fixed
    public string upgradeFrom;      // High 专属：对应的低级 affixId
    public string upgradeTo;        // Low 专属：对应的高级 affixId（空=无升级）
    public List<BuffEffectItem> effects;  // 实际效果
    public BuffScopeFilter scope;   // 作用范围
    public int weight;              // 抽取权重
}

public enum AffixTier { Low, High, Fixed }
```

## 九、设计注意事项

1. **前 5 关快速成型**：80% 低级概率确保玩家在第 5 关 Boss 前至少拿到 3~4 个低级词缀
2. **第 10 关转折点**：精英/Boss 关 50% 高级概率 + 可选第 3 种族，是 build 转型的关键节点
3. **终局 100% 固定**：第 16~20 关精英/Boss 全出固定词缀，确保终局体验的一致性和强度
4. **低级→高级覆盖**：提供"赌一把"的策略深度——先拿低级保底，还是等高级一步到位
5. **固定词缀独立性**：10 个固定词缀不互相依赖，每个都是独立的 power spike
