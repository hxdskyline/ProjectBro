## 四、BuffEffectRegistry ID 映射错误

当前 `BuffEffectRegistry.cs` 注册：

```
300 → GluttonyEffect（击杀回血）
301 → PackLeaderEffect（每友军+攻）
302 → HuntMarkInnateEffect（攻击标记）
303 → DragonEchoEffect（龙息回响）
```

但 `tribe_aura_config.json` 中：

```
300 → 淬毒之爪（攻击上毒）
301 → 亡者供养（死亡产2尸体）
302 → 灵魂连接（30%伤害转移给族长）
303 → 血肉磨坊（每尸体+1%攻速）
```

**结果：任何拥有奶牛猫 300-303 光环的单位都会触发完全错误的效果。**
