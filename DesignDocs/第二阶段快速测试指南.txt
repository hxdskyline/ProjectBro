【测试招募系统】
───────────────
触发方式：第2回合开始或点击"开始回合"

预期行为：
1. RecruitmentPanel弹出
2. 显示三个选项卡片：

   ✓ 增加小猫 (消耗200猫粮) - 绿色背景
   ✓ 品质进化 (消耗150猫粮) - 紫色背景
   ✓ 族长强化 (消耗150猫粮) - 棕色背景

□ UI显示正确
□ 选项点击有反馈
□ 猫粮正确扣除
□ 数据正确更新（新族群/小猫/品质/属性）

【测试祭祀系统】
───────────────
触发方式：第3、6、9、12、15、18回合

预期行为：
1. RitualPanel弹出

第一步：选择祭祀族群
- 显示3个族群卡片（玩家拥有的族群三选一）
- 每个卡片显示：

  * 小猫数量
  * 族长属性（攻防血速统）
- 点击族群后高亮为金色
- 确认按钮变为可点击

第二步：选择消耗档位
- 显示3个消耗档位卡片：
  ✓ 免费祭祀 (0猫粮) - 灰色背景
  ✓ 普通祭祀 (50-150猫粮) - 绿色背景
  ✓ 盛大祭祀 (400-600猫粮) - 棕色背景
- 每个卡片显示：
  * 档位名称
  * 消耗猫粮数
  * 奖励预览（奖励类型列表）
- 点击档位后高亮为金色
- 确认按钮变为可点击，显示"确认祭祀"

验证点：
□ 第一步UI正确显示
□ 族群选择有反馈
□ 第二步正确切换
□ 档位卡片显示正确
□ 猫粮正确扣除
□ 奖励正确发放：
  - 0消耗：临时加成(1-2项) + 白色小猫 + 道具 + 猫粮
  - 50-150消耗：永久加成 + 蓝紫小猫 + 道具 + 2-5倍猫粮
  - 400-600消耗：永久%加成 + 紫金小猫 + 3个道具 + 1饰品 + 3-6倍猫粮


【测试商店系统】
───────────────
触发方式：第5、10、15、20回合

预期行为：
1. ShopPanel弹出
2. 显示5个商品槽位（网格布局，1行5列）
3. 每个商品显示：
   - 商品名称
   - 商品类型（奇物/道具/小猫）
   - 价格（猫粮数）
   - 描述（简短）
4. 显示刷新按钮：
   - 显示刷新消耗（50/100/150...）
   - 点击后消耗猫粮并刷新商品列表
5. 显示关闭按钮
6. 右上角显示当前猫粮数量

交互：
- 点击商品购买（扣除猫粮，添加到库存）
- 点击刷新按钮（扣除猫粮，重新生成商品）
- 点击关闭按钮（关闭面板）

验证点：
□ 显示5个商品
□ 商品信息完整
□ 猫粮显示正确
□ 购买逻辑正确：
  - 猫粮足够则购买成功
  - 猫粮不足则无法购买（按钮禁用）
□ 刷新逻辑正确：
  - 消耗正确递增（50→100→150...）
  - 刷新后显示新商品
  - 猫粮扣除正确
□ 面板关闭逻辑正确

【错误排查】
════════════

如果JSON文件加载失败：
1. 检查路径：Assets/StreamingAssets/Tables/
2. 检查文件名是否正确
3. 检查JSON格式是否有效（可用JSON验证器）
4. Unity控制台查看具体错误信息

如果UI不显示：
1. 检查TribeBuildPanel是否在场景中
2. 检查子面板是否正确绑定
3. 查看Console是否有错误
4. 检查RectTransform设置

如果功能不工作：
1. 查看Console日志
2. 检查DataManager是否初始化
3. 确认猫粮足够
4. 检查回合是否正确（控制台会有日志）
