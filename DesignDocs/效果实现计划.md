## 第一批：修复致命 Bug + 基础调度（优先级 P0）

**目标**：修复 ID 映射错误，让已定义的效果类型能被正确调度

### 1.1 修复 BuffEffectRegistry ID 映射
- 删除 300-303 的错误注册
- 为奶牛猫 300-309 创建正确的效果类：
  - 300 `PoisonClawEffect`：攻击命中时附带中毒
  - 301 `DeadFeastEffect`：己方单位死亡时产生 2 尸体
  - 302 `SoulLinkEffect`：受到伤害时 30% 转移给族长
  - 303 `MeatMillEffect`：场上每具尸体 +1% 攻速
- 文件：`BuffEffectRegistry.cs`、新建 `Cow/` 目录下效果类

### 1.2 调度器补全效果类型分发
- 在 `LeaderSkillExecutor.ResolveEffectList` 中补充分发：
  - `ConsumeCorpse` → 调用 `CorpseManager.ConsumeCorpse()`
  - `SummonUnit` → 调用 `SummonManager.SpawnUnit()`
  - `ResurrectCorpse` → 调用 `CorpseManager.ResurrectNearestCorpse()`
- 文件：`LeaderSkillExecutor.cs`

### 1.3 奶牛猫白骨复生实现
- 配置效果：ConsumeCorpse + SummonUnit（模板 bone_kitten）
- `SummonManager` 中新增 `bone_kitten` 模板（2ATK/1HP/15s）
- 文件：`leader_skill_config.json`、`SummonManager.cs`

### 1.4 奶牛猫转生仪式实现
- 配置效果：ResurrectCorpse + Heal(50%)
- `CorpseManager` 新增 `ResurrectNearestCorpse(float healPercent)` 方法
- 文件：`leader_skill_config.json`、`CorpseManager.cs`

## 实现顺序建议

```
第一批（P0 修复 + 基础）  ← 立即开始
  ↓
第二批（狸花猫光环）     ← 种族机制最简单，先出效果
  ↓
第三批（橘猫光环）       ← 依赖第一批的尸体系
  ↓
第四批（无毛猫光环+技能） ← 依赖法力系统决策
  ↓
第五批（奶牛猫光环+橘猫技能）← 依赖元素伤害系统
```
