# 战斗力评估系统

## 1. 伤害公式

```
damage = MAX(1, attacker.ATK - defender.DEF)
```

- 纯减法，最低伤害为 1
- 没有暴击、闪避、属性克制等机制
- 攻击频率由速度决定，所有单位共享同一攻速配置

## 3. 品质系统

### 品质概率

| 品质 | 概率 | 倍率范围 | 典型值(15%) |
|------|------|----------|------------|
| 白 (White) | 40% | 0.10 - 0.20 | 10-15 ATK |
| 蓝 (Blue) | 30% | 0.20 - 0.30 | 17-26 ATK |
| 紫 (Purple) | 20% | 0.30 - 0.40 | 23-37 ATK |
| 金 (Gold) | 10% | 0.40 - 0.50 | 31-46 ATK |

倍率应用到 `catBaseStats`，例如暹罗猫基础 ATK=92：
- 白猫 (0.15)：92 × 0.15 = 14 ATK
- 蓝猫 (0.25)：92 × 0.25 = 23 ATK
- 紫猫 (0.35)：92 × 0.35 = 32 ATK
- 金猫 (0.45)：92 × 0.45 = 41 ATK

## 4. 属性计算顺序

### 族长

```
final = base × (1 + permanentPercent) + permanentBonus
final = final × (1 + temporaryPercent)   // 限时buff
final = MAX(1, final)                     // 下限为1
```

### 小猫

```
final = catBaseStats × qualityMultiplier
final = MAX(1, final)
```

小猫没有永久/临时 buff 加成（command=0）。

## 5. 速度系统

### 移动速度

```
moveSpeed = ((speedAttribute - 1000) / 1000) + 1.0
```

| SPD属性 | 移动速度 |
|---------|---------|
| 950 | 0.95 格/秒 |
| 1000 | 1.0 格/秒 |
| 1100 | 1.1 格/秒 |
| 2500 | 2.5 格/秒 |
| 3000 | 3.0 格/秒 |

### 统帅惩罚

当小猫数量超过族长统帅力(CMD)时，全队速度下降：

```
overRatio = (catCount - command) / command
penalty = MIN(overRatio × 10%, 50%)
speedPenalty = 1.0 - penalty
```

例：CMD=10，有 15 只猫：
- overRatio = (15-10)/10 = 0.5
- penalty = 0.5 × 10% = 5%（未达上限）
- 速度变为原来的 95%

例：CMD=10，有 60 只猫：
- overRatio = 5.0
- penalty = MIN(50%, 50%) = 50%
- 速度变为原来的 50%（最大减速）

## 8. 战斗日志

在 Unity Console 中查看，使用过滤器 `[BattleSummary]` 或 `[BattlePanel]`。

### 战斗开始日志

```
[BattlePanel] Battle Lv5: 2 tribes | Enemy stats ATK=105 DEF=6 HP=600 SPD=2.2
```

显示当前关卡的敌人属性和玩家上阵部族数。

### 战斗结束日志

```
[BattleSummary] WIN | Player: 15/28 alive, 2340/5935 HP | Leader: ATK=120 DEF=85 HP=980 SPD=2.8 | Enemy: 0/10 alive, 0/6000 HP | Enemy: ATK=105 DEF=6 HP=600 SPD=2.2
```

字段说明：
- `WIN` / `LOSE`：战斗结果
- `Player: 15/28 alive`：存活单位数/总单位数
- `2340/5935 HP`：玩家剩余HP/总HP
- `Leader: ATK=... DEF=...`：第一个玩家单位的属性
- `Enemy: 0/10 alive`：敌人存活数/总数
- `Enemy: ATK=... DEF=...`：第一个敌人的属性

### 过滤方法

在 Unity Console 搜索栏输入：
- `[BattlePanel]` — 查看每关的敌人属性配置
- `[BattleSummary]` — 查看每关的战斗结果
- `[BattleManager]` — 查看战斗流程事件
- `[DMG]` — 需要取消注释 `BattleSimulation.cs:239` 才会有，显示每次攻击的详细伤害

### 关键验证点

如果觉得战斗难度有问题，在日志中检查：

1. **敌人属性是否生效**：看 `[BattlePanel]` 日志中的 `ATK=` `DEF=` `HP=` 是否与 `battle_campaign_levels.json` 一致
2. **族长是否能输出**：看 `[BattleSummary]` 中 `Leader: ATK=` 是否 > 敌人 `DEF=`
3. **猫是否能输出**：族长ATK > 敌人DEF 没问题但猫打1点 → 猫ATK < 敌人DEF
4. **敌人是否构成威胁**：看敌人 `ATK=` 是否 > 族长 `DEF=`
